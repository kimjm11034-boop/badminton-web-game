# 실제 선수 자료를 적용한 경기 동작

이 기록은 경기용 기본 모델과 초기 비교 표본을 다룬다. 원천 사진 전체를 처리한 최신 모션 자료실과 직접 지정하는 게임 상황 분류는 [전체 선수 모션과 상황 분류](CATALOG.md)에 정리했다.

플레이어와 상대 선수는 같은 신체 동작 모델을 쓴다. 마우스로 서브한 뒤 상대가 리턴할 때 양 선수의 준비 자세, 체중 이동, 디딤발과 타격 팔을 볼 수 있다. 실험실에서는 원본 프레임 옆에서 관절을 확인하고, 후면·정면·측면으로 돌려 보거나 한 단계씩 멈출 수 있다. [경기](http://localhost:5173/) · [실험실](http://localhost:5173/motion-lab/) · [브라우저에서 녹화한 랠리](../evidence/game-movement.webm)

## 학습 자료와 평가

제공한 원천 ZIP 11개에는 JPG 24,170장, 라벨 ZIP 2개에는 JSON 2,178개가 들어 있다. 같은 선수가 시간에 따라 어떻게 움직이는지 학습하는 데 단식·복식·훈련 자료를 함께 사용했다. 촬영일 2022년 8월 4일을 평가용으로 통째로 남기고, 나머지 날짜의 이미지 15,341장을 움직임 후보 탐색에 사용했다. 자세 적합과 검증에는 선수가 보이고 대응 관계를 추정할 수 있는 표본을 골랐다. 원천 ZIP 11개 모두에서 움직임 쌍을 확보했다. [파일별 처리량과 평가 결과](results.json)

| 학습 대상 | 사용 자료 | 별도 촬영일에서 확인한 결과 |
| --- | --- | --- |
| 몸의 중심선 | 공식 2D 관절 라벨의 팔·다리 좌표로 머리·목·가슴·배를 추정하는 회귀 모델. 학습 3,012명분 | 1,933명분에서 평균 위치 오차가 선수 검출 상자 높이의 1.98% |
| 골반 기준 3D 자세 | 3,416개 선수 자세에서 관절 12개의 2D 좌표와 MediaPipe가 추정한 3D 관절 21개의 관계를 학습 | 1,029개 자세에서 MediaPipe 추정치와 평균 21.6cm 차이. 학습 집합의 평균 자세를 고정해 쓴 경우는 24.5cm |

표의 인원 단위는 프레임마다 검출한 선수 한 명분이다. 같은 사람이 여러 번 등장한다. 실제 3D 관절 위치, 무게중심과 지면반력은 원본에서 측정되지 않았다. 특히 깊이 방향과 가려진 관절에는 불확실성이 남는다.

## 게임에서 움직임을 만드는 방법

1. 같은 카메라와 장면의 인접 표본에서 한 선수의 관절을 연결했다. 추적이 모호한 대응을 제외한 뒤, 793개 촬영 구간에서 같은 선수의 자세 변화 1,572쌍을 얻었다.
2. 준비, 스플릿 스텝, 사이드 셔플, 후방 크로스오버, 전위 런지, 오버헤드, 점프 스매시에 대해 각 동작을 33단계로 나눴다. 각 단계에서 양팔·양다리 방향, 어깨, 척추, 보폭, 골반 높이와 변화 방향이 가까운 서로 다른 8개 구간의 관측값을 골랐다. 관측 가중 평균 85%와 작성한 단계별 기준 자세 15%를 섞은 뒤 시간축에서 부드럽게 연결했다. [동작 생성 코드](game_bank.py) · [게임이 읽는 동작 데이터](../../data/player-motion-bank.js)
3. 경기 중에는 이동 속도, 셔틀 접근 방향, 타점에 맞춰 동작을 선택한다. 지지발은 코트 좌표에 고정하고, 다음 발은 선수 이동에 맞춰 들어 옮긴다. 팔·다리는 학습 표본에서 구한 분절 길이를 유지하며 도달 가능한 타점에 라켓 줄이 닿도록 역기구학으로 보정한다. 양 선수의 해부학적 좌우는 유지하고 상대 선수는 코트에서 180도 회전한다. [경기 모션](../../motion.js)

실험실의 영상 비교 탭은 실제 JPG 시점과 보간한 시점을 구분한다. 화면의 중심점은 신체 분절로 계산한 추정치이고 영상 표본의 발 접지는 자세로부터 추정한 상태다. 경기의 발 고정과 착지 궤적은 게임 제어기가 담당한다. 제공된 시점 사이의 세밀한 손목 회전, 셔틀 충돌 순간, 발에 실린 힘을 영상으로 직접 복원한 것은 아니다. [실험실 비교 화면](../evidence/learned-body.png)

## 검증과 재현

- 실제 WebGL 경기에서 서브, 상대 리턴, 사용자 재타격과 마지막 랠리 리플레이 진입을 확인했다. [경기 화면](../evidence/game-rally.png)
- 경기 테스트 22개가 통과했다. 두 코트 방향, 가속·감속·방향 전환 중 지지발 고정, 골반 움직임, 도달 가능한 타점에서 셔틀과 라켓 줄의 접촉을 검사한다. [경기 검증 코드](../../tests/learned-motion.test.mjs)
- 실험실의 7개 기준 동작 4,207시점과 3개 영상 비교 동작 1,803시점에서 관절 좌표, 팔·다리 길이와 발 지면 높이를 확인했다. [실험실 검증 코드](../verify.mjs)

경기 실행에는 Node.js와 저장된 모델만 필요하다. 아래 재학습 명령은 원본 ZIP, 로컬 MediaPipe 모델, Python 환경에서 프로젝트 루트를 기준으로 순서대로 실행한다. 대용량 작업의 중간 결과는 `.cache/dataset-study/`에 보관한다.

```sh
python -X utf8 motion-lab/training/prepare.py
python -X utf8 motion-lab/training/moving_pairs.py
python -X utf8 motion-lab/training/fit.py
python -X utf8 motion-lab/training/game_bank.py
python -X utf8 motion-lab/training/examples.py
node motion-lab/verify.mjs
npm test
```
